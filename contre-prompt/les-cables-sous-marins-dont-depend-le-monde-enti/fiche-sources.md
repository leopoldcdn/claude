# Fiche de sources — « Les câbles sous-marins dont dépend le monde entier »

Rédigée à partir de pages **lues** pendant la production. Statuts : **Lu** (passage cité présent sur la page ouverte), **Secondaire** (chiffre lu dans un résumé ou une source qui n'est pas l'organisme d'origine, ou que je n'ai pas pu ouvrir), **Calculé**, **Simplifié**, **Faible** (hypothèse ou source indirecte), **Illustration**.

**Sujet reçu :** « Les câbles sous-marins dont dépend le monde entier — Comment une infrastructure presque invisible transporte l'essentiel des données ». L'« essentiel » est ici chiffré par l'ITU : plus de 99 % du trafic de données **entre pays** (pas « tout Internet »).

## 3. Ce que je n'ai pas pu confirmer

- **L'épaisseur exacte d'un câble** dans une source primaire (ICPC ou fabricants) : seules des sources secondaires cohérentes (17 à 25 mm).
- **La part exacte du reste du trafic** (moins de 1 %) : ni l'ITU ni l'ICPC ne la détaillent dans les pages lues.
- **Le nombre exact de câbles** : 500 (ITU, ICPC) contre 607 systèmes en service en 2026 (TeleGeography) ; la vidéo dit « plus de cinq cents ».
- **Le nombre de navires réparateurs** vient d'une seule source (renseignement naval américain, estimation) ; l'ICPC ne le donne pas dans les pages lues.
- **La date exacte de l'éruption de Tonga** n'est pas dans les pages lues ; je déduis « janvier » de la durée (38 jours avant le 22 février).
